# Discord Scheduled Bot

- `.hourly`: ogni 1 ora e 3 secondi (3603 secondi).
- `.bt all`: ogni 3 ore (10800 secondi).
- All'avvio, il primo `.bt all` parte 3 secondi dopo il primo `.hourly`.
- Canale predefinito: `748242145504264352`.

## Railway
Carica i file su GitHub, collega il repository a Railway e aggiungi nelle Variables:

DISCORD_BOT_TOKEN = IL_TOKEN_REALE_DEL_BOT

Non inserire il token nel repository GitHub.
